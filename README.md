# 📱 条码生成 (Barcode Generator)

批量条码 / 二维码生成工具，运行于 iOS [Scripting](https://scripting.fun) 应用。

支持 **QR Code** 与 5 种常用一维条码（Code 128-B / Code 39 / EAN-13 / UPC-A / ITF-14），可一次生成多条、按需自定义颜色与外观。

## ✨ 功能特性

- **多行输入**：单个输入框粘贴多行内容，勾选「每行生成一个条码」后每行生成一条；不勾选则整段作为一个条码
- **📷 扫码识别**：调用系统相机扫描表格/截图中的文字，识别结果自动换行追加进输入框
- **🛠 多格式生成**：单击「批量生成」默认生成 Code 128-B；长按可弹出选择 **QR Code / Code 128-B / Code 39 / EAN-13 / UPC-A / ITF-14**
- **⭐ 收藏**：条码页一键收藏，支持自定义名称、分类管理（新增/重命名/搜索/分组折叠）
- **🕘 历史记录**：自动记录最近生成内容，一键清空
- **🎨 样式设置**：条码颜色、背景颜色、显示文字、文字位置/大小、条码高度/宽度、边距，全部可自定义
- **🌗 外观模式**：跟随系统 / 浅色 / 深色，全界面主题自适应
- **💾 一键分享**：将条码页渲染为图片，通过系统分享面板保存到相册或文件
- **玻璃拟态界面**：毛玻璃材质、圆角卡片、点击变色反馈

## 🚀 使用

1. 将 `条码生成` 文件夹放入 Scripting 应用的 `scripts` 目录
2. 打开 Scripting，运行「条码生成」
3. 在输入框中粘贴内容（每行一条），或点底部「扫码识别」扫描文字
4. 勾选「每行生成一个条码」后点「批量生成」；长按可切换条码格式
5. 在条码页点右上角「分享」保存图片，或点星标收藏

## 🧬 支持的条码格式

| 格式 | 说明 |
| --- | --- |
| QR Code | 任意文本，使用系统原生生成 |
| Code 128-B | 任意文本（默认格式） |
| Code 39 | A-Z 0-9 - . 空格 $ / + % |
| EAN-13 | 12~13 位数字（自动计算校验位） |
| UPC-A | 11~12 位数字（自动计算校验位） |
| ITF-14 | 13~14 位数字 |

## 🎨 样式设置

左上角齿轮进入设置页，可调整：

- **外观**：跟随系统 / 浅色 / 深色
- **条码颜色 / 背景颜色**：系统取色器自由选择
- **显示文字 / 显示条码格式**：开关条码下方文字与格式标签
- **文字位置 / 文字大小**：文字位于条码上方或下方，字号可调
- **条码高度 / 条码宽度 / 边距**：滑杆实时调节

所有设置自动保存，下次运行生效。
