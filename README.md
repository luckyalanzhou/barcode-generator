# 📱 条形码生成器 (Barcode Generator)

基于 **Code 128-B** 编码的条形码生成工具，运行于 iOS [Scripting](https://scripting.fun) 应用。

## ✨ 功能

- **多行输入**：可添加任意数量的内容，同时生成多条条形码
- **📷 相机扫描**：识别照片/截图中的文字并自动填入输入框；识别到多个内容时自动拆分为多行
- **↑↓ 排序**：调整条目的生成顺序
- **− 删除**：移除不需要的条目
- **条形码纵向排列**，间距 1cm，居中显示
- **💾 一键保存**：将整页条形码渲染为图片，保存到系统相册
- **玻璃拟态（Glassmorphism）界面**：毛玻璃遮罩、圆形功能键、点击变色反馈

## 🚀 使用

1. 将 `条形码生成` 文件夹放入 Scripting 应用的 `scripts` 目录
2. 打开 Scripting，运行「条形码生成」
3. 在输入框中输入内容（可多行，每行一条；或点相机图标扫描）
4. 点击「生成条形码」，在新页面查看结果
5. 点击「保存图片」，条形码图片保存到系统相册

## 🧬 编码原理 (Code 128-B)

- 起始符 `START_B = 104`，结束符 `STOP = 106`
- 每个字符对应 11 个模块的条空模式（`PATTERNS` 表，0–105 为 11 模块，106 为 13 模块）
- 校验位 = (起始符 + Σ(字符值 × 序号)) mod 103
- 条宽 2pt、条高 80pt，宽度超限时自动按比例缩放
